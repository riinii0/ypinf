# 시연 대본 및 녹화 체크리스트 (민지의 70초)

## 페르소나
- 이름: 민지 (만 23세, 서울 동작구 자취 4학년, 본인 연소득 없음, 재학)
- 사전 채움 URL: `/find?demo=minji` (자동 제출하지 않으며, 입력 상태를 바로 보여 줄 수 있다)
- 날짜 고정: `.env`에 `DEMO_TODAY="2026-11-23"`을 넣으면 녹화와 실제 발표의 D-day가 일치한다

## 시연 동선 (총 60~70초)

| 구간 | 시간 | 화면 | 멘트·동작 |
|---|---|---|---|
| 1. 입력 | 15초 | `/` → `/find` | "내 지원금 찾기" 클릭 → 나이 23, 동작구, 소득 없음, 재학 선택 → "결과 보기" |
| 2. 합계 확인 | 20초 | `/result` | 대표 카드 "최대 예상 금액 1,416만 원"과 바로 해당 2개·확인 필요 8개 확인 |
| 3. 1위 상세 | 10초 | `/policy/[id]` | 금액순 상위 정책(청년월세 지원 480만 원 등) 클릭 → 자격 조건 비교(✔/✕/?)와 제출 서류 체크리스트 확인 |
| 4. 공식 신청 | 15초 | `/policy/[id]` → 외부 | 하단 "공식 사이트에서 신청하기" 클릭 → 공식 기관 페이지 새 탭 열림 확인 |
